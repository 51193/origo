# 生命周期策略的顺序约束

> [↑ 回到 Origo 手册](../README.zh.md)

生命周期策略使用 Before / After 相对顺序约束。顺序约束只约束同一实体的生命周期策略，不要求被引用策略挂载；主动、观察者和状态机策略沿用各自调度契约。选择单一相对顺序模型，使先后意图直接表达，避免数字排序与关系排序产生两套相互冲突的语义。

顺序约束在完整注册表中成立，实体顺序保留传递关系：A 先于 B、B 先于 C 时，只挂载 A 与 C 的实体仍须先执行 A。没有约束的候选策略按索引的 Ordinal 顺序选择，以消除注册、挂载与恢复输入顺序造成的差异。Process 和批量生命周期钩子使用同向顺序，清理钩子不自动逆序。

顺序关系只声明在策略类型特性上，不提供每实体覆盖。注册限于启动阶段；自动发现完成后（直接使用 SndWorld 时，在首次生命周期策略实体创建前）校验引用与环并固定注册表，固定后注册操作明确失败。约束中的未知索引、非生命周期策略、自引用和环均明确失败；环诊断给出实际路径。存档仅记录挂载索引，恢复时使用同一注册关系。固定关系避免运行期新增策略改变所有实体的排序。
