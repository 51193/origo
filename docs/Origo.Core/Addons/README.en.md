# Addons

> [↑ Back to Origo.Core](../README.en.md)

## Module Capability

Collection of vendor (source-imported) third-party libraries. Currently contains only the FastNoiseLite noise library. All vendor code is kept in its original, unmodified state; adaptation logic is done in outer-layer modules.
